# Proyecto RA1

## Descripción

Este repositorio está orientado a la asignatura de **Lenguajes de programación para Inteligencia Artificial**.

Su finalidad es servir como base de trabajo para el profesorado y para la organización de materiales, ejemplos y recursos relacionados con la programación aplicada a IA.

## Estructura del repositorio

- `index.html`: página principal del proyecto.
- `README.md`: documentación del repositorio.
- `data/`: carpeta para archivos de datos, ejemplos o recursos del proyecto.

## Objetivos

- Proporcionar una estructura clara y accesible.
- Facilitar la presentación de contenido docente.
- Permitir la incorporación de datos y recursos adicionales.

## Cómo usarlo

1. Abrir `index.html` en un navegador para ver la portada del proyecto.
2. Revisar esta documentación para conocer la finalidad del repositorio.
3. Añadir archivos relevantes dentro de la carpeta `data/` según sea necesario.

## Nota

Este repositorio ha sido preparado como una base inicial para el desarrollo del proyecto de la asignatura.
