# Proyecto RA1

Repositorio para organizar el desarrollo, las fuentes y las evidencias del trabajo.

## Estructura

```text
proyecto-ra1/
├── index.html              # Desarrollo del trabajo
├── README.md               # Organización, fuentes y evidencias
├── data/
│   └── trends.csv          # Exportación de Google Trends
├── assets/                 # Recursos propios, si se usan
├── pseudocodigo.ipynb      # Desarrollo del pseudocódigo
└── demo_lenguajes.ipynb    # Demostración de lenguajes
```

## Contenido

- `index.html`: página principal del proyecto.
- `README.md`: documentación del repositorio.
- `data/trends.csv`: datos exportados desde Google Trends.
- `assets/`: imágenes, gráficos u otros recursos propios.
- `pseudocodigo.ipynb`: notebook para desarrollar el pseudocódigo.
- `demo_lenguajes.ipynb`: notebook para realizar pruebas o demostraciones.
